# Campus Connect – Digital Campus Management System

## Project Overview
Campus Connect is a web-based Digital Campus Management System designed to simplify and digitalize college activities. It provides a single platform for students, faculty and administrators to manage academic information and college operations.

The system includes role-based dashboards, attendance management, assignment tracking, internal marks, timetable management, announcements and an AI-powered chatbot that acts as a virtual assistant for students.

## Objectives
- Digitalize college management activities.
- Provide separate dashboards for students, faculty and administrators.
- Automate attendance calculation and tracking.
- Manage assignments, marks and timetables.
- Improve communication through announcements.
- Provide an AI chatbot for student assistance.
- Reduce manual paperwork and improve efficiency.

## Main Features

### 1. Student Dashboard
- View personal profile.
- Check subject-wise attendance.
- View internal examination marks.
- Access assignments and deadlines.
- View class timetable.
- Receive college announcements.
- Apply for Leave / On-Duty.
- Submit grievances.
- Check fee status.
- Interact with the AI chatbot.

### 2. Faculty Dashboard
- View assigned classes.
- Mark student attendance.
- Upload internal marks.
- Create and manage assignments.
- Upload learning materials.
- Publish announcements.
- Approve or reject student requests.
- Monitor student performance.

### 3. Administrator Dashboard
- Manage student and faculty accounts.
- Manage departments and courses.
- Manage class timetables.
- Publish college announcements.
- Monitor attendance and academic records.
- View reports and dashboard statistics.
- Manage pending requests.

### 4. AI Virtual Assistant
- Answer attendance-related questions.
- Find upcoming assignment deadlines.
- Retrieve internal marks.
- Provide timetable information.
- Display recent announcements.
- Check leave request status.
- Provide personalized academic assistance.

## System Architecture

The project follows a three-layer architecture:

1. Frontend – Provides the user interface.
2. Backend – Handles application logic and user requests.
3. Database – Stores student, faculty, attendance, marks and assignment information.

## Installation and Setup

### Step 1: Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### Step 2: Open the project folder

```bash
cd CampusConnect
```

### Step 3: Install dependencies

```bash
pip install -r requirements.txt
```

### Step 4: Run the application

```bash
python app.py
```

### Step 5: Open in browser

```text
http://127.0.0.1:5000
```
